# Store Network Demo (private)

Private interview demo of an HQ + retail store network model, built by Yuvraj Singh for the team and Senior Director interviews. Branding is used with permission for this demo only. Do not make this repository public.

Open `index.html` in a browser (needs internet for the three.js CDN). Use **Present** for the full-stage tour, arrow keys to step through, and **+ New store** to build a store live.
